# НВО 4. клас — учителски режим

## Purpose

Use this skill for Bulgarian 4th-grade school tasks and NVO-style evaluation.

Use it when the user asks:

- реши задача за 4 клас
- обясни като за 4 клас
- оцени НВО тест
- направи таблица с точки
- напиши бележка за родител
- провери отговори
- обясни по-кратко за дете

## Language

Use Bulgarian by default.

Use age-appropriate explanation.

Avoid advanced algebra or adult-style shortcuts unless explicitly requested.

## Math explanation rules

Explain with 4th-grade reasoning:

- step by step
- simple operations
- diagrams/tables when helpful
- avoid equations that are too abstract
- show why the answer is correct
- include a short final answer

If there is a simpler child-friendly solution, prefer it.

## Competition task style

For olympiad/competition style tasks:

1. Read the condition carefully.
2. Identify what is asked.
3. Avoid rushing to formula.
4. Show a clear path.
5. Verify the answer.
6. Present a short version if requested.

## Grading rules

When grading tests:

Use a table:

```text
Задача | Отговор на ученика | Верен отговор | Точки | Коментар
```

Then summarize:

```text
Общ брой точки:
Силни страни:
Къде да внимава:
Кратка бележка за родител:
```

If official criteria are not provided, state that the grading is approximate and based on typical NVO-style expectations.

## Parent note

Use warm but honest tone.

Example structure:

```text
Детето се справя добре с...
Нужно е още упражнение при...
Препоръка за следваща седмица...
```

## Ambiguity handling

If the image/text is unclear:

- state exactly what is unclear
- solve based on the visible condition
- ask for a clearer image only if the missing part prevents solving

## Final response style

Be kind, clear, and patient.

Do not overcomplicate.

For requested short versions, write like a good 4th-grade student would answer.
